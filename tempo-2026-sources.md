## Boundaries and follow-up

- Inserts, autograph/relic variants, the complete Instant season, college, international and other releases remain partial. The UI can display `Tempo2026.coverageNote` to make this visible. New roster membership alone does not create cards.
- Some publisher-style checklists use numeric row positions for autograph listings where the printed card uses an alphanumeric code. Exact TCDB codes are used for the added Prizm/Donruss/Select autographs; unverified ordinal numbers are not inserted as printed numbers.
- 2026 Crown Royale was listed for December 2, after this refresh date; no speculative checklist rows were added.
- Existing catalog rows beyond the guarded Key correction were not rewritten or removed. Catalog IDs use explicit permanent variant codes. Reapplying the supplement is idempotent; any conflicting assigned ID aborts the entire update before mutations.
